# vPlexViewer

**vPlexViewer** is an iPad application designed to provide users with the ability to view configuration data from EMC's VPLEX Storage Virtualization Platform.  
This tool is particularly useful for administrators and engineers who need to monitor and manage VPLEX systems on the go.

## Features

- Visual representation of VPLEX system configurations
- Access to system status and health metrics
- User-friendly interface optimized for iPad devices

## Requirements

- **iOS Device**: iPad running a compatible version of iOS
- **VPLEX Firmware**: GeoSynchrony version 5.0 or higher (tested and optimized for version 5.0.1)

## Installation

vPlexViewer is available on the [iOS App Store](https://itunes.apple.com).

To install:

1. Open the App Store on your iPad.
2. Search for **vPlexViewer**.
3. Download and install the application.

## Usage

1. Launch the vPlexViewer app on your iPad.
2. Enter the necessary credentials and connection details for your EMC VPLEX system.
3. Navigate through the app to view configuration data and system status.
